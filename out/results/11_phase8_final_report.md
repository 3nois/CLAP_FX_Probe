# Phase 8 — 최종 결과: 오디오 단계 손실을 줄일 수 있는가 (2026-08-28)

**결론(요약)**: 줄일 수 있다 — 완전히는 아니지만, 재학습 없는 두 가지 저렴한 개입
(변위 증폭 α + 다중 시드 평균 k)을 조합하면 highshelf_gain 전범위의
directional_agreement가 Phase 6 기준선 **+0.0886 → +0.1564**로(약 1.8배)
오른다. 사전 등록 절대 기준(§5)으로는 "실용적 개선"(≥0.20)에는 못 미치고
"부분 개선"(0.10~0.20) 상단에 도달했다 — 실용 임계값의 95%CI 상단(0.194)이
0.20에 거의 닿는다.

온도 하향(C)은 예측과 달리 **효과가 없었다**. α×온도 교호작용(D)도 뚜렷하지
않았다. projection 층 야코비안 정보를 쓴 방향(8-2)은 naive 방식보다 **더
나빴다** — 이 층의 국소 유효계수가 512차원 중 평균 95개(≈19%)뿐이라는 부산물
발견이 그 이유를 설명한다.

n=100(같은 소스 부분집합) 조건에서:

```
Phase 8-1 재현치   mean=+0.0886  95%CI=[+0.0542,+0.1238]
Phase 6 목표치     mean=+0.0886  95%CI=[+0.0542,+0.1238]
```

**소수점까지 정확히 일치** — 같은 조건이면 같은 생성 경로를 그대로 재현한다는
뜻으로, 파이프라인 정확성의 강한 확인이다.

## 1. 가설 A — 다중 시드 평균 (지지됨, 유의)

`11_phase8_1b_k_average.py` — alpha=1·temp=1.0 슬라이스, 임베딩을 먼저
평균한 뒤 코사인(사전등록 방식, 체크포인트에 없던 d쪽 임베딩은 이미 저장된
오디오에서 CLAP만 다시 돌려 재추출 — 재생성 없음).

```
k=1   +0.0867 [+0.0631,+0.1132]
k=2   +0.1045 [+0.0763,+0.1351]
k=4   +0.1198 [+0.0867,+0.1556]
```

독립 CI는 겹치지만(소스 간 변동 -0.33~+0.51이 매번 섞여 들어가 검정력이 낮음),
**짝비교(같은 100소스, 소스 간 변동을 상쇄)로는 뚜렷이 유의하다**:

```
k=4 − k=1 짝비교 차이 = +0.0331,  95%CI = [+0.0202, +0.0456]  (0을 명확히 배제)
```

★ **정량적으로 순수 √k 잡음모형과 잘 맞는다**: 잡음모형이 맞다면 k=2 개선폭이
k=4 전체 개선폭의 58.6%를 차지해야 하는데, 실측은 53.7% — 매우 근접. 다만
단순 √k 스케일링이 예측한 절대 개선폭(k=1 대비 +0.087)의 **약 38%만 실현**됐다
— **잔차의 일부(추정 20~30%)는 진짜 샘플링 잡음이고, 나머지는 §0.1에서
예상한 대로 구조적/소스 고유 신호**라는 뜻이다. 시나리오 A1과 A2의 중간 —
"A1 방향으로 유의하게 지지되지만 전체를 설명하지는 못함"으로 정리한다(사전
등록에서 "A2 쪽에 약하게 기운 예측"이라 적었는데, 그보다는 A1 쪽 증거가
더 뚜렷하게 나왔다 — 예측이 틀렸다).

## 2. 가설 B — 변위 증폭 (역U자 확인, 예측 적중)

전체 격자(4,000건) 기준, α별 marginal 평균(temp+seed 전체):

```
alpha=1   da=+0.0975 [+0.0862,+0.1101]   recon=0.612 [0.605,0.620]
alpha=2   da=+0.1357 [+0.1234,+0.1478]   recon=0.589 [0.581,0.597]
alpha=3   da=+0.1370 [+0.1251,+0.1486]   recon=0.560 [0.552,0.568]  ← da 정점
alpha=5   da=+0.1230 [+0.1113,+0.1341]   recon=0.508 [0.500,0.516]
```

짝비교(같은 source×temp×seed, alpha=1 대비):

```
alpha=2 vs 1   da 차이 +0.0383 [+0.0279,+0.0490]   recon 차이 -0.0230 [-0.0294,-0.0163]
alpha=3 vs 1   da 차이 +0.0395 [+0.0285,+0.0508]   recon 차이 -0.0526 [-0.0602,-0.0451]
alpha=5 vs 1   da 차이 +0.0255 [+0.0140,+0.0377]   recon 차이 -0.1045 [-0.1127,-0.0961]
```

**예측대로 역U자** — 정점이 α=2~3(예측한 구간과 정확히 일치), α=5에서 꺾인다.
전부 alpha=1 대비 통계적으로 유의한 da 개선이다(CI가 전부 0을 배제).

**재구성 충실도는 예측보다 훨씬 덜 무너졌다**: §5 사전 등록한 "붕괴" 기준
(상대 30%↓ 또는 절대 0.15↓)에 α=5조차 못 미친다(0.1045/0.612=17.1%
상대하락, 절대값 0.508 — 둘 다 붕괴 기준 미달). §3에서 노름(2.24)이 이미
9차 하락 구간을 넘었다고 예측했던 것과 달리, **실제 재구성 충실도는 완만하게만
떨어졌다** — 노름 민감도(9차, 전체 임베딩 스케일링)와 변위만 증폭하는 이번
조작은 실제로 다른 종류의 섭동이라는 지시서의 지적이 맞았던 셈이다. 다만
da 자체는 α=5에서 이미 꺾였으므로, **재구성이 안 무너져도 방향 신호는
먼저 죽는다** — da의 역U자는 재구성 붕괴가 아닌 다른 기전(과도한 조건
벡터가 학습분포를 벗어나 방향 정보 자체가 희석/왜곡)으로 봐야 한다.

## 3. 가설 C — 온도 하향 (예측 틀림, 효과 없음)

marginal(alpha+seed 전체 평균):

```
temp=1.0   da=+0.1238 [+0.1156,+0.1317]
temp=0.7   da=+0.1228 [+0.1145,+0.1309]
```

짝비교(같은 source×alpha×seed):

```
temp 0.7 − 1.0 차이 = -0.0011  95%CI=[-0.0084,+0.0064]   ★ 0을 뚜렷이 포함, 효과 없음
```

예측("온도를 낮추면 da가 오를 것") **틀렸다**. §0.3에서 지적한 대로 temperature는
오디오 채널에만 걸리는데, 이 스케일(1.0→0.7)의 사후 확률질량 재분배만으로는
RUN 간(시드 간) 경로 발산을 억제하기에 부족했던 것으로 보인다 — A(사후 임베딩
평균)는 유의하게 통했는데 C(사전 확률 샤프닝)는 안 통했다는 건, 노이즈를
줄이는 두 메커니즘이 실제로 다르다는 걸 보여준다(A는 진짜 통계적 평균, C는
여전히 한 번의 확률적 경로를 조금 더 뾰족하게 뽑을 뿐 — 450스텝 자기회귀
과정에서 누적되는 경로 분기 자체는 못 줄인다).

## 4. 가설 D — α×온도 교호작용 (뚜렷한 신호 없음, 예측과 다른 방향 시사)

```
temp=1.0 : alpha=1 +0.0997 → alpha=2 +0.1311 → alpha=3 +0.1418(정점) → alpha=5 +0.1226
temp=0.7 : alpha=1 +0.0952 → alpha=2 +0.1403(정점) → alpha=3 +0.1322 → alpha=5 +0.1233
```

예측("낮은 온도가 정점을 더 큰 α쪽으로 옮길 것")과 **반대 방향**처럼 보인다
(temp=0.7의 정점이 α=2로 temp=1.0의 α=3보다 오히려 이르다) — 그러나 두 정점
근방 CI가 서로 크게 겹쳐서(temp=1.0,α=3: [0.126,0.159] vs temp=0.7,α=2:
[0.124,0.158]) **확정적인 반전으로 해석하지 않는다.** 결론: 이 격자
해상도(α 4점)에서는 뚜렷한 교호작용을 검출하지 못했다 — 예측은 틀렸다고
판정하되 "반전"까지는 과잉해석하지 않는다.

## 5. 조합 — 최선의 저비용 처방

α(B)와 k(A)는 서로 다른 메커니즘(전자는 조건 신호 자체를 키움, 후자는
샘플링 잡음을 줄임)이므로 **같이 쓸 수 있는지 직접 확인**했다(같은 저장된
오디오에서 재추출, 추가 생성 없음). α=2(B에서 α=2·3 동률 1위 중 대표로 선택),
4시드 임베딩 평균:

```
α=2, k=1(단일 생성 평균)     da=+0.1198 [+0.0925,+0.1491]
α=2, k=4(임베딩 평균)        da=+0.1564 [+0.1217,+0.1939]   ← 최종 최선
짝비교 k=4−k=1               +0.0366  95%CI=[+0.0261,+0.0468]  (유의)
```

**+0.1564**는 Phase 6 기준선(+0.0886) 대비 **약 1.77배**, 순수 임베딩 단계
(cos 0.71~0.82)에는 여전히 크게 못 미치지만, 재학습 없이 "α=2로 증폭 주입 +
4번 생성해 임베딩 평균"만으로 얻어지는 결과다. 95%CI 상단(0.194)이 §5의
"실용적 개선"(0.20) 문턱에 근접한다.

## 6. Phase 8-2 게이트 (완료, 실패 — 오디오 검증 생략)

`out/results/11_phase8_2_gate.md` 요약: naive 방향(v=e_dry−e_wet) 대비
야코비안 정보 방향(pinv(J)@d_target)이 α=2,3에서 오히려 더 나쁘고
(diff -0.14, -0.06), α=5에서도 겨우 +0.02로 사전 등록 게이트 임계값(0.05)
미달 — **모든 α에서 게이트 미통과**. 사전 등록 규칙대로 오디오 검증은
생략한다.

**부산물 발견**(§0.2 정정과 연결): e_wet 지점에서 야코비안(1024×512)의
특이값 분해 결과, 국소 유효계수가 평균 95.2/512(≈19%, 범위 45~201)에
불과했다 — 512차원 입력 방향의 약 80%가 그 지점에서 1차 미분상 이미 죽어
있다(ReLU 비활성). 10차의 "6~41% 선택적 약화"보다 훨씬 강한 발견이며,
왜 야코비안 기반 방향 찾기가 이 스케일에서 안 통하는지 설명한다 — 죽어있는
방향 정보로는 아무리 정교하게 풀어도 나머지 20%짜리 부분공간 안에서만
움직일 수 있고, 그 부분공간이 실제 목표 방향과 완전히 정렬돼 있지도 않다.

## 7. 실패 시나리오 재평가

사전 등록한 "넷 다 효과 없으면 조건화 구조 변경이 유일한 처방"이라는
시나리오는 **적용되지 않는다** — A와 B는 실제로, 통계적으로 유의하게
통했다(조합 시 기준선의 1.8배). 다만 C는 효과가 없었고, D는 불확실하며,
8-2(구조 정보 활용)는 명확히 실패했다. **부분적 성공**이 이번 Phase의
정직한 요약이다: 손실은 순수하게 "구조적이고 손 못 대는" 것도 아니고,
순수하게 "샘플링 우연"인 것도 아니다 — 둘 다 실재하고, 저렴한 개입으로
그중 잡음 성분(그리고 조건 강도 부족분)의 상당 부분을 되찾을 수 있지만,
전부는 아니다. 남은 간극(0.156 vs 임베딩 단계 0.71~0.82)은 여전히
재학습 없이는 못 좁힐 가능성이 높다는 원래의 결론 방향은 유지된다 — 다만
"넷 다 무효" 만큼 강하지는 않고, "일부는 유효, 조합하면 약 2배"로 약화해서
받아들여야 한다.
