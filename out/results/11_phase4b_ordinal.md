# Phase 4b — 이펙트 축의 순서형 지표 병기

AMI 는 25구간을 무관한 25범주로 취급해 인접 구간 적중에 점수를 주지 않는다.
이펙트 레벨은 순서형이므로 이 처리가 체계적으로 불리하며, 명목형인 악기
패밀리와의 배수 비교를 이펙트 쪽에 불리하게 기울인다.

Phase 4 와 동일한 분할(GroupShuffleSplit 5겹, test 0.3, seed 0)
과 동일한 예측기를 쓰고 지표만 추가했다.

## 1. 같은 예측을 두 지표로 읽기

분류기(LogisticRegression)의 **동일한 예측 구간**에 대해 AMI 와 Spearman ρ 를 함께 낸다.

| 축 | n | AMI | Spearman ρ | 비고 |
|---|---|---|---|---|
| distortion_drive_db | 1200 | 0.1905 | **0.8341** | 같은 예측, 다른 지표 |
| reverb_room_size | 1200 | 0.1533 | **0.7637** | 같은 예측, 다른 지표 |
| highshelf_gain | 1200 | 0.1462 | **0.7733** | 같은 예측, 다른 지표 |

## 2. 순서 구조를 온전히 쓰는 경우

회귀기(Ridge)의 연속 예측에 대한 Spearman ρ 와 R².

| 축 | Spearman ρ | R² |
|---|---|---|
| distortion_drive_db | **0.8945** | 0.7873 |
| reverb_room_size | **0.8484** | 0.6993 |
| highshelf_gain | **0.8605** | 0.7228 |

## 3. 배수 비교에 미치는 영향

```
악기 패밀리 AMI            0.7732   (명목형 — 잃을 순서 구조 없음)
이펙트 AMI                 0.1462 ~ 0.1905   (순서형 — 구조 폐기됨)
  → 배수                   4.06 ~ 5.29배

이펙트 Spearman ρ (동일 예측)  0.7637 ~ 0.8341
  → 같은 예측기가 순서형 지표로는 훨씬 높게 읽힌다
```

**판정** — 배수는 AMI 기준값이며, 순서형 편향이 포함된 **상한**으로 보고해야 한다.
악기가 더 강하다는 방향 자체는 유지되나, 배수를 그대로 인용해서는 안 된다.

⚠️ Spearman ρ 와 AMI 는 척도가 달라 직접 비교할 수 없다. 위 표는 *같은 예측이
지표에 따라 얼마나 다르게 읽히는지* 를 보이는 것이지 두 값을 등치하는 것이 아니다.

## 4. 배수는 비닝 해상도의 함수다 ★

악기 과제는 10클래스다. 이펙트 축을 같은 10구간으로 비닝하면 **클래스 수가 일치한
비교**가 된다. 아래는 Phase 4 `11_phase4_1200.md` 에 이미 산출되어 있던 값이다.

| 축 | AMI (B=10) | AMI (B=25) |
|---|---|---|
| distortion_drive_db | 0.2963 | 0.1905 |
| reverb_room_size | 0.2462 | 0.1533 |
| highshelf_gain | 0.2370 | 0.1462 |

```
악기 AMI 0.7732 대비 배수

  B = 25 기준     4.06 ~ 5.29 배      ← 기존 보고값
  B = 10 기준     2.61 ~ 3.26 배      ← 클래스 수를 맞춘 값
```

**같은 데이터인데 비닝 해상도에 따라 배수가 1.6배 차이 난다.**

구간을 잘게 쪼갤수록 순서형 축이 불리해진다 — 인접 구간 혼동이 늘어나는데 AMI 는
그것에 점수를 주지 않기 때문이다. 명목형인 악기 과제에는 이 손실이 없다.

<callout>
★ 이는 §5.1(R² 의 범위 종속성)과 **같은 종류의 문제**다.
R² 가 측정 범위의 함수였듯, 여기서는 배수가 **비닝 해상도의 함수**다.
어느 쪽이든 "지표값 하나"를 보고하려면 그 값이 무엇의 함수인지 함께 밝혀야 한다.
</callout>

**보고 방식** — 배수를 단일 수치로 인용하지 않는다.

> 악기 정체성 대비 이펙트 정보량은 AMI 기준 **비닝 해상도에 따라 2.61~5.29배** 약하다
> (B=10 에서 2.61~3.26, B=25 에서 4.06~5.29). 이펙트 레벨이 순서형이고 악기 패밀리가
> 명목형이므로 이 배수에는 이펙트에 불리한 편향이 포함되어 있으며, 따라서 **격차의
> 상한**으로 해석해야 한다.
