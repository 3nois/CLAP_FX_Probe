# 03. 손잡이 방향 예측 (8차)

[02_resolution_and_family.md](02_resolution_and_family.md)에서 손잡이가 소스 고유임을 확인한 뒤, "그 방향을
dry 임베딩만으로 예측할 수 있는가"를 검증한 단계. 재렌더링 없이 `out/caches/oat_emb.npz`만
사용. 프로젝트 개요는 [../README.md](../README.md) 참고.

## 스크립트 역할

| 스크립트 | 역할 |
|---|---|
| `21_handle_predict_phase1.py` | 정방향(A: e_dry→방향) / 역방향(B1·B2) 예측 모델 학습·평가 |
| `22_handle_predict_phase2.py` | 크기 예측(B3), 복원 검증(C), LOFO 일반화 진단(D) |

## 핵심 결과

- 정방향 예측 held-out cos 0.78~0.86 — 악기군 평균 기준선(0.34)을 크게 상회
- 역방향(B2, 파라미터 미지 조건) cos 0.71~0.82 — 방향은 예측 가능, 크기는 사용자 슬라이더로 분리
- B1(파라미터 기지, 상한) 대비 B2의 손실은 1~5%p로 작음
- LOFO(훈련에 없던 악기군)에서는 0.20~0.24p 하락하지만 여전히 악기군 기준선보다 높음 — 완전 일반화도 완전 암기도 아님
- 판정: 세 이펙트 전부 cos>0.6 → 임베딩 단계에서 손잡이 구현 가능
