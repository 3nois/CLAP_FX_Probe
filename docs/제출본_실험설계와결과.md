# 4. 공통 설계

Q1~Q6은 하나의 렌더링 자산을 공유한다. 이 장은 그 공통 기반을 서술하고,
질문별 절차는 §5의 각 항에서 다룬다.

## 4.1 데이터

NSynth test 셋에서 악기 패밀리별 120개씩 **1,200개 소스**를 층화 추출했다(10 패밀리,
고정 시드). 소스 목록은 `src_id`로 고정되며 모든 축·모든 질문이 동일 목록을 재사용한다.

원본은 16 kHz 단음 4초다. 렌더링은 48 kHz에서 수행하되 **소스 내용은 8 kHz 이하에만
존재**한다는 제약이 축 설계 전반에 반영되었다(§4.4).

## 4.2 이펙트 구현과 범위 근거

`pedalboard`(Spotify, JUCE 기반)로 적용한다. 결정론적 C++ DSP이므로 동일 입력·파라미터에
대해 재현이 보장된다.

파라미터 범위는 **Koo et al.(2023)의 구현 범위**를 채택했다. 대상 논문의 augmentation이
해당 코드를 사용하므로, 그 범위 밖의 측정은 대상 논문에 대한 진술이 되지 않는다.

대상 논문이 "EQ"로 지칭한 처리는 단일 필터가 아니라 **5밴드 파라메트릭 캐스케이드**
(로우셸프 + 벨 3 + 하이셸프, 동시 적용)임을 상류 저장소에서 확인하고 그대로 재현했다.

$$
H_s(f)=\prod_{b=1}^{5} H_b\bigl(f;\ s\cdot g_b\bigr),\qquad
f_b\in\{100,\ 400,\ 2000,\ 3000,\ 6500\}\ \text{Hz}
$$

밴드 게인 $g_b$는 소스별 고정 시드에서 추출하고, 축 변수 $s\in[0,1]$이 다섯 밴드를
동시에 스케일한다.

## 4.3 축 구성 — 23축 × 25레벨

한 축만 변화시키고 나머지를 고정하는 **OAT(one-at-a-time) 격자**를 쓴다. 변위 벡터
$v=e(\theta_{\max})-e(\theta_{\min})$를 축마다 직접 산출해야 하므로 무작위 샘플링
설계는 적합하지 않다.

| 계열 | 축 | 범위 | 격자 | 고정 조건 |
|---|---|---|---|---|
| distortion (1) | `drive_db` | 0 ~ 20 dB | 선형 | — |
| reverb (4) | `wet_level` | 0 ~ 0.5 | 선형 | room 0.5 · damp 0.1 · width 0.7 |
| | `room_size` | 0.05 ~ 0.85 | 선형 | wet 0.3 |
| | `damping` | 0 ~ 1.0 | 선형 | |
| | `width` | 0 ~ 1.0 | 선형 | |
| EQ gain (3) | `highshelf_gain` | −15 ~ +15 dB | 선형 | cutoff 2000 Hz · q 0.7071 |
| | `lowshelf_gain` | −15 ~ +15 dB | 선형 | cutoff 100 Hz |
| | `peak_gain` | −15 ~ +15 dB | 선형 | cutoff 1000 Hz |
| EQ cutoff (6) | `highshelf_cutoff` | 500 ~ 4000 Hz | 로그 | gain ±6 dB 두 벌 |
| | `lowshelf_cutoff` | 30 ~ 200 Hz | 로그 | 〃 |
| | `peak_cutoff` | 200 ~ 6000 Hz | 로그 | 〃 |
| EQ q (6) | 3 타입 | 0.1 ~ 2.0 | 로그 | gain ±6 dB 두 벌 |
| cascade (1) | `eq_cascade_intensity` | 0 ~ 1.0 | 선형 | 5밴드 동시 스케일 |
| 널 (2) | `null_12k_gain` | −15 ~ +15 dB | 선형 | HighShelf @ 12 kHz |
| | `null_15k_gain` | −15 ~ +15 dB | 선형 | HighShelf @ 15 kHz |

주축 21 + 널 2, 각 25레벨. **575,000회 렌더링.**

**게이팅** — 게인이 0이면 cutoff·q를 변화시켜도 필터가 항등에 가까워 신호가 변하지
않으므로, 해당 축은 게인을 열어 두어야 성립한다. 또한 부호별로 분리해야 한다 —
게인 부호에 따라 cutoff 변화가 만드는 변위가 서로 반대 방향이기 때문이다.

$$
\cos\bigl(v_{\text{gain}+},\,v_{\text{gain}-}\bigr)=
\begin{cases}
-0.499 & \text{highshelf}\ (119.9°)\\
-0.684 & \text{lowshelf}\ (133.2°)\\
-0.758 & \text{peak}\ (139.3°)
\end{cases}
$$

두 분기를 합산하면 상쇄되어 무작위 널과 구분되지 않는다.

## 4.4 Nyquist 제약

소스가 16 kHz이므로 내용은 8 kHz 이하에만 존재한다. 세 지점에 반영되었다.

```
highshelf cutoff    상한 4000 Hz — Koo 원본 범위는 8 kHz 를 넘어 스윕 절반이 무효
cascade high_shelf  6500 Hz — Koo 기본 8000 Hz 는 Nyquist 와 일치해 사용 불가
                    밴드 순서 보존:  100 < 400 < 2000 < 3000 < 6500 < 8000
널 축               12 kHz · 15 kHz — 필터는 정상 작동하나 처리할 성분이 없다
```

**널 축의 설계 의도**는 "처리하지 않음"이 아니라 **"실제 DSP 연산을 수행하되 효과가
없어야 함"** 이다. 이로써 렌더링·인코딩 경로 자체가 만드는 바닥을 분리한다.

## 4.5 dry 앵커

각 축의 $\theta_{\min}$은 진짜 dry가 아니다.

```
distortion 레벨 0    drive 0 dB 이나 tanh(x) 이므로 항등이 아님
reverb 레벨 0        room 0.05 이나 wet_level 0.3 으로 잔향이 존재
gain 축 레벨 12      0 dB — 유일하게 정확한 no-op (bypass 와 cos = 1.0000000)
```

따라서 **명시적 bypass 렌더링 1,200개**를 모든 축의 공통 기준점으로 별도 산출했다.
Q6의 검색 라이브러리가 이 자산이다.

## 4.6 통계 규약

```
분할       패밀리 층화.  Q3·Q4 는 80/10/10,  Q6 은 60/20/20
불확실도   소스 단위 부트스트랩 (기본 500회, Q6 은 1,000회), 95% CI
통제       셔플 라벨 · 널 축 · 상한 통제(악기 분류)
초매개변수  검증 분할에서만 선택하고 시험 분할은 1회만 평가
사전 등록   각 단계 실행 전 예측과 판정 기준을 문서로 고정
```

# 5. 질문별 결과

## 5.1 Q1 — CLAP 임베딩에 이펙트 정보가 있는가

**설계.** 축마다 25레벨 임베딩에 릿지 프로브를 적합해 held-out $R^2$를 낸다.
단일 범위가 아니라 **구간 중심 × 구간 폭의 2차원 곡면**으로 산출한다. 통제는
셔플 라벨(신호 파괴)과 널 축(효과 없는 실제 연산) 두 가지다.

**결과.**

| 축 | 20% 폭 (하위⅓) | 전 범위 |
|---|---|---|
| distortion_drive_db | 0.153 | **0.802** |
| highshelf_gain | 0.116 | **0.734** |
| reverb_room_size | 0.034 | **0.712** |
| peak_gain | 0.064 | **0.681** |
| reverb_wet_level | 0.116 | **0.619** |
| lowshelf_gain | 0.013 | **0.302** |
| null_12k_gain (통제) | 0.000 | 0.006 |
| null_15k_gain (통제) | 0.000 | 0.000 |

널 축 두 개를 같은 표에 둔다. **절대값으로 보면 실제 축과 널이 명확히 갈리지만,
비율로 요약하면 갈리지 않는다** — 배수(전범위/좁은폭)는 널 축이 23.6배·29.4배를
내므로 결과 지표로 쓰지 않는다.

같은 폭 안에서도 위치에 따라 갈린다 — `reverb_room_size` 20% 폭 기준
하위 0.034 / 중위 0.094 / 상위 **0.252**.

셔플 통제는 전 축에서 0 근처 음수, 널 축은 $R^2\le0.0064$였다.

**판정.** 정보는 **있다.** 다만 보고 가능한 $R^2$가 측정 구간에 따라 크게 달라지므로,
*"$R^2$가 얼마다"* 라는 진술은 측정 구간을 명시하지 않으면 성립하지 않는다.

> 보고된 $R^2$는 표현의 속성이 아니라 **측정 구간의 속성**이다.

### 5.1.1 범위 무관 지표 — 분해능

**설계.** $R^2$가 범위에 종속되므로 축 간 비교에 쓸 수 없다. 대신 인접 격자 쌍의
변위가 널 바닥을 넘는 최소 간격(JND)을 측정한다. 범위 선택과 무관한 양이다.

**결과.**

| 축 | JND | 실무범위 대비 | 측정 상태 |
|---|---|---|---|
| reverb_wet_level | 2.08e−05 | ≤ 0.004% | **좌측 절단** |
| lowshelf_cutoff | 0.011 | **0.006%** | 검출 |
| peak_cutoff | 14.7 | **0.254%** | 검출 |
| q 축 3종 | ~0.013 | ≤ 0.68% | 미검출 |
| highshelf_cutoff | ~45.3 | ≤ 1.29% | 미검출 |
| distortion_drive_db | 0.280 dB | **1.399%** | 검출 |
| eq_cascade_intensity | 0.014 | **1.399%** | 검출 |
| reverb_room_size | 0.023 | **2.894%** | 검출 |
| reverb damping·width | ~0.042 | ≤ 4.17% | 미검출 |
| gain 축 3종 | 0.604 dB | **4.024%** | 검출 |

**측정 상태 세 부류.** *검출* 은 20단계 미세 격자 5~19번째에서 문턱을 찾은 정밀
측정값이다. *미검출* 6축은 어느 개별 구간도 단독으로 널을 넘지 못해 상한만 확정된다
— 측정 실패가 아니라 문턱 없이 점진 누적되는 축이라는 결과다. *좌측 절단* 은
`reverb_wet_level` 1축으로, **미세 격자의 첫 점에서 이미 널을 넘어** 더 잘게 재지
못했다. 실제 문턱은 이보다 작을 수 있으므로 정밀 측정값과 나란히 인용하지 않는다.

**판정.** 정밀 측정된 8축의 분해능 차이는 약 **671배**다(0.006% ~ 4.024%).
절단된 7축은 상한만 확정되므로 이 범위 산정에서 제외한다.
**축 간 비교는 이 표로만 한다** — $R^2$는 측정 구간에 종속되어 쓸 수 없다.

## 5.2 Q2 — 있다면 악기 정체성 대비 얼마나 강한가

**설계.** 클래스 수가 다른 두 대상(악기 10종 대 이펙트 레벨 25구간)을 비교해야
하므로, 우연 보정되고 클래스 수에 무관한 **조정 상호정보량(AMI)** 을 쓴다.
악기 분류는 상한 통제 역할을 겸한다 — 프로브가 읽어낼 수 있는 최대치를 정한다.

**결과.**

```
악기 패밀리 10종    AMI 0.7732 · U 0.7843 (레이블 엔트로피의 78.4% 회복)
                   accuracy 0.8400 (우연 0.100)
이펙트 대응 3축     AMI 0.1462 ~ 0.1905
배수               4.06 ~ 5.29
```

**판정.** 이펙트 정보는 존재하되 악기 정체성보다 **4~5배 약하다.**

| 대상 논문의 진술 | 판정 |
|---|---|
| 이펙트 정보가 **없다** | **기각** |
| 이펙트 정보가 **미약해 활용되지 못한다** | **지지** |

이 구분은 수사가 아니라 처방을 가른다. 정보가 없다면 인코더를 교체해야 하고,
쓰이지 않는 것이라면 조건화 경로만 손보면 된다.

## 5.3 Q3 — 이펙트를 조작하는 방향이 소스마다 다른가

**설계.** 소스별 변위 벡터 $v$를 단위화한 뒤, 동일 소스 내 구간 간 코사인(`within`)과
상이 소스 간 코사인(`between`)을 비교한다. 차이(gap)의 신뢰구간을 소스 단위
부트스트랩으로 낸다. **Q4·Q5의 전제**에 해당한다 — 손잡이가 소스마다 다르지 않다면
방향 예측이라는 과제 자체가 성립하지 않는다.

**결과.**

```
distortion   within 0.4185   between 0.2973   gap 0.1213 [0.1147, 0.1284]
highshelf    within 0.3931   between 0.2521   gap 0.1410 [0.1328, 0.1494]
reverb_room  within 0.4394   between 0.3042   gap 0.1352 [0.1277, 0.1427]
```

전 축·전 구간에서 `within > between`이며 gap의 CI가 0을 배제한다.

**판정.** 손잡이는 **소스 고유하다.** 악기군은 그 차이의 일부만 설명하고 나머지는
개별 소스에 귀속된다.

## 5.4 Q4 — 그 방향을 예측할 수 있는가

**설계.** MLP 듀얼헤드(512→1024→512), 코사인 손실, 패밀리 층화 80/10/10.
**패밀리 라벨은 주지 않는다.** 조건을 둘로 나눈다.

```
B1   파라미터 값을 아는 조건    상한 참고용
B2   파라미터 값을 모르는 조건   ★ 실사용에 해당하는 진짜 질문
```

기준선은 `between` 코사인이다 — 소스 정보를 쓰지 않고 전역 평균 방향을 답했을 때의
성적에 해당한다.

**결과.** B2 기준.

| 축 | 구간 | B2 | between 기준선 |
|---|---|---|---|
| highshelf_gain | 전범위 | **0.8239** | 0.2521 |
| | 하위⅓ | 0.7828 | 0.1712 |
| distortion | 전범위 | **0.8015** | 0.2973 |
| | 하위⅓ | 0.7421 | 0.2602 |
| peak_gain | 전범위 | 0.8007 | 0.2356 |
| lowshelf_gain | 전범위 | 0.7252 | 0.1778 |
| reverb_room_size | 전범위 | 0.7065 | 0.3042 |

**20개 조합(5축 × 4구간) 전부가 기준선을 넘었다.**

**판정.** 예측 **가능하다.** 하위⅓에서도 성립하므로 약하게 걸린 소리에서도 방향이
회복된다. 이는 도구 성립 조건 중 임베딩 단계 요건이 충족됨을 뜻한다.

$$
\text{읽기 단계 요약}:\quad \cos = 0.707 \sim 0.824\quad (34.6°\text{--}45.1°)
$$

## 5.5 Q5 — 예측한 방향이 실제 생성 오디오에 반영되는가

**설계.** 예측 방향으로 이동시킨 임베딩을 TokenSynth에 주입해 오디오를 생성하고,
생성물을 다시 CLAP으로 인코딩해 **변위 방향**을 원본과 비교한다.

$$
\mathrm{da}=\cos\bigl(
\underbrace{e_{\text{regen}}(\hat e_{\text{dry}})-e_{\text{regen}}(e_{\text{wet}})}_{v_{\text{generated}}},\
\underbrace{e_{\text{dry}}-e_{\text{wet}}}_{v_{\text{original}}}\bigr)
$$

절대 위치가 아니라 변위 방향을 보는 이유는 재구성 충실도가 낮아($\cos 0.25\text{--}0.65$)
생성물이 두 원본 모두에서 멀기 때문이다. 41,280건을 생성했다.

**결과.**

| 축 | 전범위 | 하위⅓ | 중위⅓ | 상위⅓ | n |
|---|---|---|---|---|---|
| highshelf_gain | **+0.0954** | +0.0359 | +0.0400 | +0.0398 | 1200 |
| peak_gain | +0.0624 | +0.0256 | +0.0322 | +0.0264 | 1200 |
| distortion | +0.0633 | +0.0345 | +0.0172 | +0.0259 | 600 |
| reverb_room_size | +0.0462 | +0.0009 | +0.0168 | +0.0381 | 960 |
| lowshelf_gain | +0.0325 | +0.0093 | +0.0182 | +0.0127 | 1200 |

20개 조합 중 19개가 CI로 0을 배제한다. 유일한 null은 `reverb 하위⅓`로, 시간축
이펙트가 가장 약하리라는 사전 예측과 일치한다.

**판정.** 통계적으로는 반영되나 **실용적으로는 반영되지 않는다.**

$$
\text{임베딩 } 34.6°\text{--}45.1°
\quad\longrightarrow\quad
\text{오디오 } 84.5°\text{--}88.1°
\qquad(\text{무작위 널 } 89.97°)
$$

$n$이 크므로 작은 효과도 유의하게 검출되나, 무작위에서 2~6도 벗어난 방향 일치로는
제어 수단이 되지 않는다. **유의성과 실용성은 다르다.**

### 5.5.1 손실 지점의 특정

**설계.** 조건화 경로의 세 후보를 각각 직접 측정한다.

**결과.**

| 장애 | 실측 |
|---|---|
| projection 층의 국소 계수 부족 | 유효계수 $95.2/512\ (19\%)$, 범위 45~201 |
| 조건 채널의 경쟁 | 이펙트 신호가 악기 신호의 1/4~1/5 (§5.2) |
| 자기회귀 샘플링의 확률성 | 분산 분해 잔차 57.4% |

유효계수는 실제 네트워크의 정확한 autodiff로 산출했다. **입력 방향의 약 81%가 이
지점에서 1차 미분상 소멸한다.** 조건화가 시퀀스 맨 앞 **프리픽스 토큰 하나**로
이루어지므로 악기 정체성과 이펙트가 1024차원 벡터 하나를 공유한다.

**판정.** 세 장애가 **모두 생성기 내부에 있다.** 표현의 속성이 아니다.

### 5.5.2 기전 가설의 검정 — 개입 실험

**설계.** 세 장애에 각각 대응하는 개입을 요인 실험으로 시험한다(3,200건 생성).
통하는 것과 통하지 않는 것의 **패턴**이 가설을 검정한다.

**결과.**

| 개입 | 대응 장애 | 결과 |
|---|---|---|
| 다중 시드 평균 $k$ | 샘플링 확률성 | **통함** +0.0331 [+0.0202, +0.0456] |
| 변위 증폭 $\alpha$ | 채널 경쟁 | **통함** 역U자, 정점 $\alpha=2\text{--}3$ |
| 온도 하향 | 샘플링 확률성 | 안 통함 −0.0011 [−0.0084, +0.0064] |
| 야코비안 방향 설계 | 계수 부족 | 실패 (사전 게이트 미통과) |

$$
\alpha=2,\ k=4:\quad +0.1564\ [+0.1217,\ +0.1939]\quad (81.0°)
$$

기준선 대비 **1.77배**를 재학습 없이 얻는다.

**판정.** 가설이 **지지된다.** 사후 평균(통함)과 사전 확률 첨예화(안 통함)가 갈린 것은
두 방식이 서로 다른 잡음원에 작용함을 뜻하며, 야코비안 설계의 실패는 유효계수 19%와
정합적이다. 다만 1.77배로도 실용 수준에 이르지 못하므로, **조건화 구조를 바꾸지 않고는
생성 경로로 해결되지 않는다.**

## 5.6 Q6 — 생성이 아닌 다른 경로로는 전달되는가

**설계.** §5.5.1의 세 장애가 모두 생성기 $g$ 내부에 있으므로, $g$를 경유하지 않는
하류 과제에서는 무효화되어야 한다. 검색이 그러한 과제다.

$$
\text{생성}:\ e_{\text{wet}}\to\hat e_{\text{dry}}\xrightarrow{\ g\ }\text{오디오}
\qquad
\text{검색}:\ e_{\text{wet}}\to\hat e_{\text{dry}}\to
\arg\max_{x\in\mathcal L}\cos\bigl(\hat e_{\text{dry}},\,e(x)\bigr)
$$

검색은 역문제를 풀지 않고 라이브러리에서 최근접 항목을 고르므로, 필요한 것은
$\hat e_{\text{dry}}$의 **방향이 옳다는 것뿐**이다. 기존 캐시만 사용하며 CLAP 재계산이
없다. 네 팔을 비교한다.

```
R0   무처리          q = e_wet                     기준선
R1   예측 방향        q = unit(e_wet + α v̂)          ★ 진짜 질문
R3   전역 평균 방향    q = unit(e_wet + α v̄)          소스 정보 없음 — 핵심 대조
Ror  실제 보정 방향    q = unit(e_wet + α v_true)     α 격자 하의 상한
```

$\alpha$는 검증 분할에서만 선택하고 시험 분할은 1회만 평가한다.

**축 선택.** 무처리 기준선이 포화된 축은 개선을 정의할 수 없다.

| 축 | 무처리 R@1 | 무처리 R@10 | 판정 |
|---|---|---|---|
| highshelf_gain (+15 dB) | 0.9150 | 1.0000 | 천장 — 제외 |
| reverb_room_size (0.85) | 0.5142 | 0.8408 | 채택 |
| distortion (20 dB) | 0.2958 | 0.7583 | 채택 |

EQ 축의 포화 자체가 소견이다 — **EQ는 CLAP 임베딩상의 정체성을 거의 변화시키지
않는다.** 생성 경로에서 신호가 가장 강했던 축(§5.5의 highshelf)과 정반대다.

**결과 (1) — 회수율.** 라이브러리는 bypass 임베딩 1,200개, 정답은 질의 소스의 bypass
항목이다. 정답이 렌더링으로 **구성된 것**이므로 별도 검증을 요하지 않는다.

| 축 | lvl | R0 | R3 | **R1** | Ror |
|---|---|---|---|---|---|
| distortion | 24 | 0.2500 | 0.3750 | **0.4875** | 0.9792 |
| | 18 | 0.3750 | 0.5292 | **0.6083** | 0.9708 |
| | 12 | 0.6125 | 0.7083 | **0.7375** | 0.9750 |
| reverb | 24 | 0.4667 | 0.6250 | **0.6875** | 0.9500 |
| | 18 | 0.6542 | 0.7042 | **0.8292** | 0.9708 |
| | 12 | 0.7250 | 0.7958 | **0.8542** | 0.9667 |

**R1이 R0와 R3를 6/6 전부 유의하게 이긴다**(R@10 대응 부트스트랩 95% CI 하한 > 0).
R1의 R@10은 0.9625~1.0000이다. 패밀리 보존율은 하락하지 않고 6/6 유의 상승했다
(예: distortion lvl24 0.8167 → 0.9583).

R3도 대부분 R0를 이기므로 "dry 방향으로 이동하는 것 자체"가 유효하다. 그 위에서
R1이 R3를 추가로 이기는 것이 **§5.3(소스 고유성)의 실용적 가치**를 뒷받침한다.

**결과 (2) — 실사용 조건.** 질의 소스를 라이브러리에서 제외하고 wet 항목을 혼합한다
(전체 3,600, 무작위 기준 0.3333).

| 축 | lvl | R0 dry@10 | R1 dry@10 |
|---|---|---|---|
| distortion | 24 | 0.0138 | **0.7808** |
| | 18 | 0.0396 | **0.7388** |
| reverb | 24 | 0.0317 | **0.7796** |
| | 18 | 0.0963 | **0.6179** |

패밀리 보존율은 0.93~0.98로 유지된다. CLAP 외부의 물리 지표 8종(THD·crest·스펙트럼
중심·8 kHz 이상 에너지비·잔향 감쇠·C50/C80)을 병행 측정했으며, distortion은 3/4
지표가, reverb는 최대 강도 구간에서 4/4 지표가 R1을 지지한다.

**판정.** 전달 **된다.** 생성 경로에서 소실된 동일한 방향 정보가 검색 경로에서는
하류 과제로 전달된다.

## 5.7 부수 결과 — 축 구조

도구 설계에 필요한 사실들이며 Q1~Q6의 논증에는 직접 쓰이지 않는다.

**회전.** context를 바꿔도 손잡이 방향은 크게 틀어지지 않는다 — 15건 중 14건에서
context가 부차적이거나 무관했고, 부호 분기 내부의 회전은 25°~37°로 무작위 널
$[85°,95°]$에서 멀다.

**상호작용.** 전조합 ANOVA(제곱합 직접 분해, 모델 가정 없음).

```
highshelf (gain × cutoff × q)
  주효과     gain 48.9%   q 18.9%   cutoff 7.9%
  2차       gain×q 10.7%   gain×cutoff 6.8%   cutoff×q 2.8%
  3차 이상   4.0%
```

`cutoff`는 단독으로 약하나 `gain`과의 상호작용에서 나타난다 — 게이트 구조가 수치로
확인된다.

**도구 사양.** 사전 확정 기준(주효과 ≥ 50% & 상호작용 < 30% → 독립 노출).

```
독립 노출     peak::gain (60.8%)   ·   reverb::wet_level (58.6%)
조건부 노출   0개
보류          11개
```

## 6.1 핵심 대조

동일한 방향 정보를 동일한 소스에서 두 경로로 전달했다.

$$
\begin{aligned}
\text{임베딩 단계} &:\quad 34.6° \sim 45.1°\\
\text{생성 경로} &:\quad 84.5° \sim 88.1° \qquad (\text{무작위 널 } 89.97°)\\
\text{검색 경로} &:\quad \text{R@10 } 0.96 \sim 1.00,\ \ 6/6\ \text{유의 개선}
\end{aligned}
$$

**한쪽만 살아남았다.** 표현 자체에 정보가 없었다면 양쪽 모두에서 소실되었을 것이므로,
병목은 표현이 아니라 **생성 경로**에 있다.

생성 경로의 손실 지점도 특정했다 — projection 층의 국소 유효계수 $95.2/512$(19%),
프리픽스 토큰 하나를 악기 정체성과 이펙트가 공유하는 조건 채널 경쟁, 자기회귀
샘플링의 잔차 57.4%. **세 장애가 모두 생성기 내부에 있다.** 이에 대응하는 개입을
요인 실험으로 시험해 재학습 없이 1.77배를 회복했으나(α=2, k=4), 실용 수준에는
이르지 못했다.

## 6.2 유의성과 실용성의 구분

Q5에서 20개 조합 중 19개가 통계적으로 유의했다. 그러나 전범위 값 5개 중 **4개가
무작위 널의 95% 범위 내부**에 있다. 평균은 $n=1{,}200$으로 정밀하게 추정되어 0을
유의하게 벗어나지만, **개별 생성물 하나는 무작위와 구별되지 않는다.**

도구는 평균이 아니라 개별 소리를 다룬다. 이 구분이 Q5의 판정을 *"유의하나 실용적이지
않다"* 로 만든다.

# 7. 의의

## 7.1 대상 논문에 대하여

TokenSynth는 증강 학습 모델의 이펙트 적용이 부정확한 원인을 *"CLAP 음색 임베딩이
오디오 이펙트 정보를 결여하고 있기 때문(likely due to)"* 으로 추정했다[1, §V-A].
이는 청취 관찰에 근거한 추정이며 임베딩을 직접 측정한 절차는 논문에서 확인되지 않는다.

본 연구는 그 진술을 두 갈래로 나누어 판정했다.

| 해석 | 판정 | 근거 |
|---|---|---|
| 이펙트 정보가 **없다** | **기각** | $R^2$ 0.302~0.802, 널 대비 명확히 분리 |
| 이펙트 정보가 **미약해 활용되지 못한다** | **지지** | 악기 대비 4~5배 약함 |

**이 구분은 처방을 가른다.** 정보가 없다면 인코더를 교체해야 하고, 쓰이지 않는
것이라면 조건화 경로만 손보면 된다. 후자가 훨씬 싸다.

나아가 논문이 명시하지 않은 인과의 중간 고리를 측정했다. 증강의 효과가 지표에 따라
갈린 것(음색·스펙트럼 악화, MIDI 준수도 개선)은 **이펙트가 바꾸는 성분에서만
악화되었다**는 뜻이며, 이는 조건 경로의 정보 결여를 직접 가리킨다.

## 7.2 프로빙 방법론에 대하여

이 프로젝트 바깥으로 일반화되는 항목은 두 가지다.

**(1) $R^2$는 표현의 성질이 아니라 측정 범위의 함수다.**
같은 축·같은 데이터인데 측정 구간에 따라 $R^2$가 0.013에서 0.302로, 0.034에서
0.712로 변한다. 단일 범위의 $R^2$ 하나만 보고하는 관행은 표현의 성질이 아니라
**저자의 범위 선택**을 보고하는 것이다. 범위 무관 지표(분해능)를 병기하거나
범위를 축으로 하는 곡면을 보고해야 한다.

**(2) 프로빙 성공은 제어 가능성을 함의하지 않는다.**
프로빙 문헌은 표현에서 속성을 읽어낸 뒤 *"모델이 그 속성을 안다"* 고 결론짓는 일이
많다. 그러나 읽는 것과 그것으로 하류 과제를 수행하는 것은 별개이며, 그 간극은
**같은 축·같은 소스·같은 단위로 측정 가능하다.** 본 연구는 한 사례에서 그 간극을
$34.6° \to 84.5°$로 정량화하고 기전을 특정했다.

두 항목은 오디오 이펙트라는 주제와 무관하게 표현 프로빙 일반에 적용된다.

## 7.3 도구 설계에 대하여

세 장애가 모두 생성기 내부에 있다는 사실은 **생성기를 고치는 대신 지나가지 않는**
처방을 함의한다. 검색은 역문제를 풀지 않으므로 국소 계수 부족이 무관하고, 조건
채널을 쓰지 않으므로 경쟁이 없으며, 샘플링이 없으므로 확률성이 없다. 필요한 것은
예측 방향이 옳다는 것뿐이며 그것은 Q4에서 확인된 양이다.

실무적으로도 열등하지 않다 — 생성 도구의 품질 상한은 모델 성능이지만, 검색 도구의
품질 상한은 **라이브러리 자체의 품질**이다. 재학습이 필요 없고 기존 캐시만으로
동작한다는 점도 실용적 이점이다.

다만 **본 연구가 지지하는 진술은 여기까지다.**

> 방향 정보는 생성 경로에서는 소실되지만 검색이라는 하류 과제로는 전달된다.

*"검색으로 작동하는 도구가 있다"* 는 주장은 청취 검증을 요구하며, 본 연구는 그
검증을 수행하지 않았다.

# 8. 한계

**규모** — 예비 연구다. 데이터셋 1종(NSynth), 이펙트 3계열, 개입 실험은 축 1개,
검색 실험은 축 2개. 단독 논문 규모가 아니며 후속 검증이 필요하다.

**소스 도메인** — NSynth는 16 kHz 단음 4초다. 8 kHz 위에 내용이 없어 고역 셸프
측정이 원천적으로 제한되었고, Koo 원본의 high_shelf 대역을 그대로 재현할 수 없었다.
또한 NSynth는 dry가 아니다(reverb 태그 25%, distortion 태그 23%). 태그로 필터링하는
것은 해법이 아니다 — 태그가 악기 패밀리와 상관되므로 태그로 거르면 악기로 거르는
것이 되어 Q2의 비교를 직접 교락시킨다. **태그를 공변량으로 두는 층화 분석**이 올바른
대응이며 아직 수행하지 않았다.

**청취 검증 부재** — 이 연구의 가장 큰 한계다. Q6의 M1은 정답이 렌더링으로 구성되어
있어 청취를 요구하지 않으나, M2는 정답이 정의상 없어 물리 지표에 의존한다. **물리
지표는 청취가 아니다** — THD나 감쇠 시간이 dry 쪽으로 이동해도 지각적으로 부적절할
수 있다. 정식 A/B 청취(n≥10, 이중맹검) 없이는 *"도구로 쓸 만하다"* 는 진술을 할 수
없다. 예비 청취 24건에서는 이펙트 판별이 10/13(비유의, $p=0.09$)이었고 절반 가까이가
"차이 없음"이었다.

**사후 분석의 비중** — 세 항목이 사후에 이루어졌다.

```
Q6 자체        Q5 가 부정된 뒤에 추가된 질문. 축 선택도 천장 효과를 본 뒤의 결정
물리 지표       dry 기준값을 전역 평균에서 소스별로 교정한 뒤 판정이 바뀜
C50/C80        리버브 지표를 사후에 추가.  lvl24 를 제외하면 결론이 이 지표에 의존
```

완화 요인은 있다 — 유효성 게이트가 8개 지표 중 아무것도 배제하지 않아 지표 선택
자유도가 실제로 행사되지 않았고, 기준값 교체는 결과와 무관한 논리적 모순(무처리
검색이 질의 자신보다 "더 dry"하게 채점됨)으로 정당화된다. **그럼에도 사후 분석은
확증이 아니라 가설 생성이며,** 사전 등록된 재실험이 있어야 확증적으로 인용할 수 있다.

**표본 규모의 비대칭** — EQ의 `cutoff`·`q` 축은 게인 부호별로 두 벌을 구성했으나
$-6$ dB 계열 6축은 400소스만 렌더링했다(나머지는 1,200소스). 좁은 구간에서 검정력이
부족해 이 6축은 넓은 창의 값만 산출되며, 다른 축과 나란히 비교할 수 없다. Q3의 전 축
확장(15축)에서도 제외했다.

**측정 상태가 갈리는 지표** — 분해능(JND)은 15축 중 8축만 정밀 측정되었다. 6축은
문턱 없이 점진 누적되어 상한만 확정되고, `reverb_wet_level` 1축은 미세 격자의 첫
점에서 이미 널을 넘어 **더 잘게 재지 못했다**(좌측 절단). 축 간 범위(671배)는 정밀
측정 8축으로만 산정했다.

**$R^2$ 배수를 보고하지 않는 이유** — 범위 종속성을 "전범위/좁은 폭" 비율로 요약하면
분모가 0에 가까운 축에서 폭주한다. 신호가 없어야 할 널 축이 23.6배·29.4배를 내어
실제 축과 구분되지 않으므로 절대값 보고로 교체했다. 15축 중 9축이 분모 $R^2 < 0.02$
였고 1축은 전범위 $R^2$가 음수다. **범위 종속성이라는 결론 자체는 절대값으로 그대로
지지된다** — 바뀐 것은 근거의 제시 방식이다.

**예측 조건의 관대함** — Q4의 "파라미터 미지" 조건은 레벨 2지선다다. 실전은 연속
범위이므로 불확실성이 더 크며, 조건 간 격차가 작게 나온 것은 설정이 관대해서일 수 있다.

**미산출** — 물리 지표의 무처리 대비 신뢰구간을 내지 않았다. 현재 표는 질의 대비이므로
*"검색이 도움이 되는가"* 는 답하지만 *"예측한 방향이 도움이 되는가"* 는 답하지 않는다.
회수율에서는 두 대비를 모두 산출했으므로 이 공백은 물리 지표에 한정된다.
